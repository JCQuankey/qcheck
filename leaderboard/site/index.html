Get started

Run a local review

Install qcheck-quantum from PyPI, then review your file:

pip install qcheck-quantum
qcheck verify your-circuit.py --json

The CLI and GitHub Action are free and open source. qcheck reviews your code locally without executing it or sending telemetry.

What qcheck reviews

qcheck v0 reviews static signals — no execution required, so it runs safely on untrusted model output inside an agent loop or CI.

Scope

What it does — and doesn't

In scope

  • Static review of Qiskit / OpenQASM snippets
  • Common, avoidable failures
  • CI and agent preflight
  • Machine-readable JSON output

Not in scope

  • Hardware execution
  • Algorithm correctness or formal proof
  • PQC migration
